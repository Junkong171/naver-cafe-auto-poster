# F-001: 대표사진(썸네일) A/B 로테이션 + 게시 시각 변경

- 관련 파일: `cafe_poster.py`, `config.example.json`, `README.md`

## 목적

목록에서 보이는 대표사진(첫 번째 첨부 사진)이 조회수에 가장 큰 영향을 주는 것으로 보여, 두 가지 썸네일을 **같은 기간에 번갈아** 올려 어느 쪽이 더 읽히는지 비교한다. 주 단위로 바꾸면 게시판 전체 조회수가 주마다 출렁여서(다른 글 중앙값 13 → 16 → 12) 썸네일 효과를 구분하기 어렵기 때문이다.

함께, 조회수가 가장 높았던 시간대(21시 글 중앙값 18, 00시 14)에 맞춰 게시 시각을 `00:00 / 12:00` → `12:00 / 21:00`으로 옮긴다. 시각 변경은 코드 수정 없이 설정과 예약 등록만 바꾼다.

## 현재 동작 (코드 근거)

- `cafe_poster.py:188` `attached_images(cfg)`: `config.json`의 `attach_images` 목록을 그대로 첨부한다. 첫 번째 사진이 대표사진이 된다.
- `cafe_poster.py:211` `post_article()`이 위 목록을 첨부해 올린다. 어떤 시간대 글인지(slot)는 모른다.
- `cafe_poster.py:288` 게시 전 검토(`check_before_post`)에서 `attached_images(cfg)`를 불러 사진 파일이 있는지 미리 확인한다.
- `cafe_poster.py:236` `post_times(cfg)`: 게시 시각은 `config.json`의 `post_times`(없으면 `["00:00", "12:00"]`).
- `cafe_poster.py:398` 미리보기는 `images/{파일 이름}`으로 첨부 사진을 보여준다.

## 동작 시나리오

1. `config.json`에 `"thumbnail_rotation": ["thumb_a.png", "thumb_b.png"]`가 있으면, 글마다 이 목록에서 대표사진 1장을 골라 `attach_images`의 **첫 번째 사진 자리에** 넣는다. (나머지 첨부 사진이 있으면 그대로 뒤에 붙는다.)
2. 고르는 규칙: `(날짜 번호 + 그날 시간대 순서) % 목록 길이`. 사진이 2장이면
   - 어떤 날: 12:00 → A, 21:00 → B
   - 다음 날: 12:00 → B, 21:00 → A
   - 이렇게 날마다 순서가 바뀌어 "A는 늘 낮, B는 늘 밤"이 되지 않는다.
   - 같은 시간대 글은 몇 번을 다시 시도해도 같은 사진을 고른다 (보충 게시 포함).
3. 글을 올리면 `log.txt`에 `대표사진: thumb_a.png` 줄이 "글쓰기 성공" 줄 바로 앞에 남는다.
4. `thumbnail_rotation`이 없거나 비어 있으면 지금처럼 `attach_images`를 그대로 쓴다.
5. 미리보기(`preview`)는 **다음에 올라갈 시간대**의 대표사진을 보여주고, 터미널에 그 파일 이름과 시각을 출력한다.

## 사용자가 직접 할 일 (구현·검증 후)

1. 초안 사진을 영문 이름으로 복사해 둔다: `images/thumb_a.png`(초안 A), `images/thumb_b.png`(초안 B). — Claude가 복사 가능 (비밀 파일 아님)
2. `config.json`에 `"thumbnail_rotation": ["thumb_a.png", "thumb_b.png"]`를 추가하고, `"post_times": ["12:00", "21:00"]`으로 바꾼다.
3. 예약을 다시 등록한다 (새 시각으로 PC 깨우기 작업이 바뀜).
4. 다음 정시 글 뒤 `log.txt`에서 `대표사진:` 줄과 "게시판 확인: 정상적으로 1개 올라감"을 확인한다.
